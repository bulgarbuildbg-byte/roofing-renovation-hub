# Замяна на стария телефонен номер (визуални варианти)

При предишната замяна бяха обновени само "сбитите" формати (`0884997659`, `+359884997659`), но **визуалният формат `089 397 1873`** остана на много места в сайта.

## Какво ще се направи

Замяна на всички останали варианти на стария номер с новия `089 397 1873` в ~65 файла (компоненти, страници, преводи, edge функции, index.html):

| Стар вариант | Нов вариант |
|---|---|
| `089 397 1873` | `089 397 1873` |
| `0893 971 873` | `0893 971 873` |
| `+359 893 971 873` | `+359 893 971 873` |
| `+359 89 397 1873` | `+359 89 397 1873` |

Команда:
```bash
FILES=$(grep -rlE "089 397 1873|0893 971 873|\+359 ?884 ?997 ?659|\+359 ?88 ?499 ?7659" \
  --include="*.ts" --include="*.tsx" --include="*.xml" --include="*.html" \
  --include="*.json" --include="*.toml" --include="*.md" . | grep -v node_modules)

echo "$FILES" | xargs sed -i \
  -e 's/089 397 1873/089 397 1873/g' \
  -e 's/0893 971 873/0893 971 873/g' \
  -e 's/+359 893 971 873/+359 893 971 873/g' \
  -e 's/+359 89 397 1873/+359 89 397 1873/g'
```

Верификация: `grep -rE "499 ?7659|884 ?997 ?659"` трябва да върне 0 резултата.

## Без промени
Дизайн, лейаут, бизнес логика, email, EIK, адрес, база данни, RLS, маршрути, преводи на текстове.
