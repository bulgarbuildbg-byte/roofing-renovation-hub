# Смяна на телефонния номер в целия сайт

## Цел
Замяна на стария телефонен номер `088 499 7659` (във всички формати) с новия номер `089 397 1873` навсякъде в кода.

## Обхват
Открити са 71 файла, които съдържат стария номер — Header, Footer, Contact, MobileBottomBar, FloatingCallButton, всички страници за услуги/градове/блог, sitemap XML-и, schema.org JSON-LD блокове и Supabase edge функции (chat, generate-quote-pdf).

## Намерени формати на стария номер
- `0884997659` (без интервали, напр. `tel:0884997659`)
- `0884 997 659` (с интервали)
- `+359884997659` (международен формат)
- `tel:+359884997659`

## Заместване с новия номер
- `0884997659` → `0893971873`
- `0884 997 659` → `0893 971 873`
- `+359884997659` → `+359893971873`

## Подход
Глобално търсене и замяна с `sed` върху всички съответни файлове (без `node_modules`), стартирано в правилния ред (първо най-дългите/специфични форми, после кратките):

```bash
FILES=$(grep -rl -E "0884997659|0884 997 659|\+359884997659" \
  --include="*.ts" --include="*.tsx" --include="*.xml" \
  --include="*.html" --include="*.json" --include="*.toml" \
  --include="*.md" . | grep -v node_modules)

echo "$FILES" | xargs sed -i \
  -e 's/+359884997659/+359893971873/g' \
  -e 's/0884 997 659/0893 971 873/g' \
  -e 's/0884997659/0893971873/g'
```

След това верификация с `grep -r "884997659\|884 997 659"` за нула резултати.

## Без промяна
- Дизайн, layout, бизнес логика
- Имейл адрес, фирмени данни (EIK, адрес)
- База данни и RLS политики
- Routes и преводни ключове
